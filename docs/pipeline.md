# От адаптации до публикации

1. **Выбери ролик** на дашборде, открой «Адаптация», нажми «В работе».
2. **Проверь «Риски»**: заполни пропуски `[реальный факт]`, сверь цифры на дату съёмки.
3. **Если хочется своего поворота**, внизу адаптации «Переписать под мою идею» и «Сохранить вариант».
4. **Персонаж в нейронке.** Один раз создай своего персонажа (Higgsfield Soul ID или набор из 10–20 своих фото). Плейсхолдер `[ARUT character reference]` в промптах = этот персонаж.
5. **Генерация кадров.** «Все промпты» копирует сториборд целиком. Кадры по 3–5 секунд, 9:16.
6. **Голос.** Текст из «Сценарий» начитай сам или через свой голосовой клон.
7. **Монтаж.** Склейка по таймкодам сценария, плашки из поля `overlay`, музыка.
   Вариант на автомате: Hypit (open-source, github) пересобирает формат референса с твоим контентом.
8. **Публикация.** Подпись и ключевое слово из блока «Подпись». Настрой автоответ в директ на ключ (лид-магнит из поля «Что отправлять по ключу»).
9. **Нажми «Снято».**

## Чего не делать

- Не копировать кадры, музыку и текст оригинала: берём механику, а не контент.
- Не ставить чужие логотипы, персонажей кино и реальных публичных людей в кадр.
- Не показывать лица детей.
- Не обещать доход и не давать сигналы в роликах.
